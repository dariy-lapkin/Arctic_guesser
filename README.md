# Арктическая угадайка

Интерактивная географическая игра: угадайте, где сделаны фотографии, и отметьте предполагаемое место на карте российской Арктики.

## Как играть

1. Посмотрите на фотографии текущего раунда.
2. Нажмите на предполагаемое место на карте. Для ответа доступны регионы российской Арктики, выделенные на карте.
3. Сравните свою отметку с правильным местом и переходите к следующему раунду.
4. В конце игры увидите общий результат из 10 заданий. Игру можно пройти заново.

На карте есть управление масштабом: увеличить, уменьшить и вернуть исходный вид. Оранжевая отметка показывает ваш ответ, зелёная — правильное место.

## Запуск

Проект не требует сборки, установки зависимостей или отдельного сервера.

- **Локально:** скачайте `index.html` и откройте его в браузере.
- **GitHub Pages:** загрузите `index.html` и `README.md` в корень репозитория. В настройках репозитория откройте **Settings → Pages**, выберите публикацию из нужной ветки и папки `/ (root)`. После публикации игра откроется по адресу GitHub Pages вашего репозитория.

**Важно:** фотографии загружаются из Wikimedia Commons, поэтому для их отображения требуется интернет-соединение. Карта и логика игры встроены в HTML.

## Что внутри

- 10 раундов: Архангельск, Норильск, Териберка, Кузомень, Билибино, плато Путорана, Нарьян-Мар, Кимжа, Салехард и Воркута.
- Интерактивная карта субъектов России; кликабельны 10 регионов российской Арктики.
- Проверка ответа по региону и расстоянию до правильной точки.
- Прогресс по раундам, текущий процент угаданных мест, масштабирование карты и финальный экран с результатом.
- Адаптивная вёрстка для компьютеров и мобильных устройств.

## Фотографии и лицензии

Фотографии загружаются напрямую из Wikimedia Commons. Под каждым снимком указаны автор, лицензия и ссылка на страницу исходного файла. Условия повторного использования зависят от лицензии конкретной фотографии; при повторном использовании соблюдайте её требования.

Геометрия регионов встроена в SVG-карту внутри `index.html`. Если вы будете заменять карту или повторно использовать геоданные отдельно, проверьте источник, атрибуцию и лицензионные условия исходного GeoJSON.

## Технологии

HTML, CSS, JavaScript и SVG. Внешние библиотеки и сборщик не используются.
